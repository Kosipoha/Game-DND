# Game-DND

## Run

Open `index.html` in a browser, or start a local server from this directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

The current prototype includes a bilingual menu and character creator, a persistent hero sheet, level-gated world map, turn-based d20 combat, class abilities, enemy drops, city shops, services and repeatable contracts, and inventory-based equipment. Music and asset attribution are documented in [CREDITS.md](CREDITS.md).
